# สคริปต์วิเคราะห์ (ทดสอบ 28 พ.ย. 2569)

สคริปต์ชุดนี้ใช้รันผลเทสในโฟลเดอร์ `../ผลเทส-28พย69/` ซ้ำ หรือลองกับพื้นที่อื่น ข้อมูลทุกตัวฟรีและไม่ต้องใช้ API key

## ติดตั้ง

```bash
cd "Industrial Waste/analysis"
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp sites.example.json sites.local.json   # แล้วใส่พิกัดจริง
```

`sites.local.json` อยู่ใน `.gitignore` เพราะ repo นี้เป็นสาธารณะ จึงไม่ใส่พิกัดจุดที่สงสัย ถ้าต้องการพิกัดที่ใช้ในเทสรอบนี้ ให้ขอจากเจ้าของงานโดยตรง หรือหาเองตามวิธีในหัวข้อ "หาพิกัดบ่อจากข่าว"

## สคริปต์

| ไฟล์ | ทำอะไร | ผลที่ได้ |
|---|---|---|
| `fetch_registries.py` | ดาวน์โหลดทะเบียนที่ทิ้งขยะชุมชน (กรมควบคุมมลพิษ) และทะเบียนโรงงาน 101/105/106 (กรมโรงงานฯ) | `data/pcd_sites.json` (3,965 จุด มีพิกัด), `data/diw_101_105_106.csv` (ปราจีนบุรี 168 ใบอนุญาต ไม่มีพิกัด) |
| `registry_check.py` | เทสที่ 1: เทียบพื้นที่ที่ดาวเทียมจับได้กับที่ทิ้งในทะเบียน ใช้ 2 กฎ ได้แก่ กฎเดิม "พืช → ดินโล่ง" และกฎใหม่ "สว่างขึ้นมาก" | ระยะจากจุดทะเบียนถึงขอบพื้นที่ที่จับได้ + ภาพ `out/registry_*.jpg` |
| `flood_s1.py` | เทสที่ 2: ขอบเขตน้ำท่วมจากเรดาร์ Sentinel-1 รายวันที่ ใช้วงโคจรเดียวกันทุกภาพ | พื้นที่น้ำท่วม (ตร.กม.) และ % น้ำท่วมในรัศมี 1 กม. รอบบ่อ + `out/flood_*.png` |
| `flowpath_dem.py` | ลากเส้นทางน้ำตามความลาดจาก Copernicus DEM 30 ม. | ในที่ราบน้ำท่วมใช้ไม่ได้ (ดูผล) ลองกับที่ที่มีความลาดได้ |
| `rgb_timeline.py` | ตัดภาพสีจริงรอบบ่อหลายวันที่ พร้อมจุดเก็บน้ำ | `out/rgb_*.jpg` |
| `common.py` | ฟังก์ชันที่ใช้ร่วมกัน (อ่านภาพ, NDVI, BSI) | |

## ตัวเลขที่รันซ้ำได้ (ตรวจแล้ว 28 พ.ย. 2569)

- `registry_check.py` ที่ทิ้ง อบต.ท่าตูม: พื้นที่เปิดใหม่ 6.34 ha ห่างจุดทะเบียน 92 ม. (ทะเบียนแจ้งขนาด 16 ไร่ ≈ 2.6 ha)
- `flood_s1.py` รอบบ่อฝังกลบ ต.หัวหว้า: น้ำท่วมในรัศมี 1 กม. คือ 0% (19 ก.ย.) → 53% (1 ต.ค.) → 7% (13 ต.ค.) → 0% (24 พ.ย.) · ทั้งกรอบ 12×11 กม. มีน้ำท่วม 49.3 ตร.กม. วันที่ 1 ต.ค.
- `flowpath_dem.py`: ความสูงที่บ่อราว 3.9 ม. · เส้นทางหยุดหลังระดับต่ำลงเพียง 0.24 ม.

## หาพิกัดบ่อจากข่าว (วิธีที่ใช้ในเทสนี้)

ข่าวและทะเบียนโรงงานบอกแค่หมู่ ตำบล และเลขโฉนด จึงต้องหาจากภาพประกอบข่าวแทน:

1. หาแผนที่ในข่าว เช่น แผนที่จุดเก็บน้ำของ สคพ. ใน[ประชาไท 4 ต.ค. 2569](https://prachatai.com/journal/2026/10/118991)
2. จดรูปร่างที่เห็นในแผนที่ เช่น บ่อหลายบ่อ ลานกำแพงขาว ถนนโค้ง และบ่อสีฟ้าข้างถนน
3. เปิดภาพ Sentinel-2 ของตำบลนั้น (`rgb_timeline.py` หรือ EO Browser) แล้วไล่หาจุดที่รูปร่างตรงกันทั้งหมด
4. จดพิกัดลง `sites.local.json` เท่านั้น ห้าม commit

## ข้อจำกัด

- เกณฑ์ทุกตัวตั้งจากภาพคู่เดียวหรือพื้นที่เดียว ยังไม่ได้ปรับ ได้แก่ กฎสว่างขึ้นเกิน 800 และสว่างเกิน 2000 (หน่วยค่าสะท้อน × 10,000) และเรดาร์ต่ำกว่า −18 dB ถือว่าเป็นน้ำ
- เรดาร์นับนาข้าวที่มีน้ำขังเป็นน้ำด้วย
- ดาวเทียมเห็นน้ำและกอง แต่ไม่เห็นสารเคมี และแยกน้ำดำออกจากน้ำใสที่ลึกไม่ได้
- "อยู่ในทะเบียน" ไม่ได้แปลว่าปลอดภัย และ "ไม่อยู่ในทะเบียน" ไม่ได้แปลว่าผิดกฎหมาย
