# ติดตามกากอุตสาหกรรมที่ถูกลักลอบทิ้ง

ทิศทางที่สามของทีม: ใช้ภาพดาวเทียมฟรีหาบ่อกากที่ผิดปกติ ให้คนในพื้นที่ช่วยยืนยัน แล้วลากเส้นทางน้ำจากบ่อไปดูว่าหมู่บ้าน นา บ่อปลา และจุดรับน้ำประปาไหนอยู่ปลายน้ำ พื้นที่นำร่องคือ อ.ศรีมหาโพธิ และ อ.กบินทร์บุรี จ.ปราจีนบุรี

ข้อมูล ณ 26 พฤศจิกายน 2569 ตอนนี้อยู่ขั้นแนวคิดสำหรับ pitch ยังไม่ได้สร้างระบบจริง

## ระบบทำงาน 5 ขั้น

1. **หา**: ดาวเทียม Sentinel-2 เทียบภาพปีต่อปีในฤดูเดียวกัน คัดจุดผิดปกติ
2. **ยืนยัน**: คนในพื้นที่ส่งรูปจากถนนผ่าน LINE (ไม่เปิดเผยตัวตน) และเจ้าหน้าที่ดูภาพก่อน–หลัง
3. **รู้ทางไป**: ลากเส้นทางน้ำจากบ่อตามความสูงพื้นที่และเส้นคลอง
4. **บอกคน**: แจ้งคนที่อยู่ปลายน้ำ และส่งรายการตรวจให้เจ้าหน้าที่
5. **ติดตาม**: ตรวจบ่อเดิมซ้ำทุกครั้งที่มีภาพใหม่ เก็บภาพเป็นไทม์ไลน์

## สถานะ

- ขั้น 1 ทดสอบกับภาพจริงแล้ว 2 รอบ: พื้นที่ 1,225 ตร.กม. ระบบคัดเหลือ 41 จุด ดูด้วยตาแล้วน่าสงสัย 3 แห่ง
- ขั้น 3–4 ยังเป็นแนวคิด ยังไม่ได้ทดสอบ
- AI 6 ตัว (คัดจุดดาวเทียม, ตรวจรูปจากชาวบ้าน, ผู้ช่วย LINE, จับน้ำท่วมจากเรดาร์, ร่างข้อความแจ้ง, ติดตามรายบ่อ) เป็นแนวคิดพร้อมแผนทดลอง T1–T4 ยังไม่ได้ฝึกโมเดล ผลทดสอบดาวเทียมตอนนี้ใช้กฎจากดัชนี (บทที่ 4 ในเล่มหลัก)
- ไฟไหม้บ่อกากและฮาร์ดแวร์เป็นแผนพัฒนาต่อ ไม่ใช่งานปัจจุบัน
